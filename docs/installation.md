# Installation

## :simple-pypi: PyPI

sshls is distributed as a Python package to
[PyPI](https://pypi.org/project/ssh-config-ls/),
you can install it with [`uv`](https://docs.astral.sh/uv) (recommended),
[`pipx`](https://pipx.pypa.io/stable/) or `pip`:

```sh
# Install with uv
uv tool install ssh-config-ls

# Update
uv tool upgrade ssh-config-ls

# Uninstall
uv tool uninstall ssh-config-ls
```
